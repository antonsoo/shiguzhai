# A boundary in the reference, not a change in the bell

The current exhibit lets a learner move A4 in whole hertz. It cannot show where
one classification changes, which source entries cross together, or whether a
changed label changes the total. Extend that experiment in the existing room.

The central operation is to cross an analytically calculated boundary while
retaining the same source entries. A second reference stays fixed for comparison.
Both sides use the currently selected object group and entry policy; the held
reference is not a separately frozen historical argument.

The main new visual is a continuous A4 ruler with a step profile of the number
of occupied modern keys. Every boundary comes from a reported integer frequency,
not from a sampled sweep. Ordinary text gives the crossing entries, their table
positions, old/new labels and old/new totals. A keyboard-operable boundary picker
and previous/next controls supplement the ruler. The existing photographs and
frequency diagram remain the exhibit's visual anchors.

```text
current grouping + retained entries
              |
430 Hz -------+---|-------|--|----------------------- 450 Hz
                 exact modern label boundaries
              |                       |
      held reference           current reference
              +---- same reported frequencies ----+
```

Use the exhibit's existing Atkinson typeface and Chinese font. The palette
continues water blue #edf3f5, deep teal #17383f, A-position teal #006a70,
B-position purple #783d78, and gray #526970. White surrounds the data. Purple
identifies the count profile; teal identifies the held reference. These colors
already have roles in this exhibit. Avoid adding ornamental instrument panels,
new cards, a separate hero, or a third room. Left-align prose; align numeric
columns by place. On a phone, put the ruler before the boundary controls and
keep the comparison table horizontally scrollable inside its own region.

The extra decimal places describe a computed modern reference boundary. They
do not increase the precision of the original acoustic measurements. No rounding
interval, measurement error bar, ancient pitch reference or probability is
inferred. The range 430–450 Hz remains the original exhibit's modern comparison
range. Finite sine tones continue to use the reported frequencies.

Save the boundary map as CSV and the two-reference comparison as SVG. The
existing illustrated reading and JSON include the investigation. Share links
retain both references. Verify the source PDF against a fresh publisher copy,
the analytical boundaries against independent high-precision calculations,
and actual saved files, keyboard behavior and offline operations in both engines.

Local source commits, a complete build and review receipts are the deliverables.
