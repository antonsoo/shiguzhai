# Review record

Reviewed 22 October 2026 UTC. This record distinguishes source transcription,
modern reference calculations, browser artifacts and the original experiment.

## What changed during review

The first version used a fixed 440 Hz modern grid. Inspection of the 269 Hz value
showed that its nearest-key classification was close to a boundary. The final
interface allows a 430–450 Hz modern reference, keeps the actual marks fixed,
and shows how 440 to 439 Hz changes the all-observation count from ten to nine.
The range is explicitly a modern analytical choice.

Source wording was tightened after reading the methods: the experiment describes
repeated strikes, but the lists contain no per-frequency occurrence counts. The
complete table footnotes are bundled. The source-table reader has row and column
headers and a keyboard-scrollable region, with the prose staying within a phone's
viewport. The four-page printed reading preserves original photographs, the
rotated full source page and its modern Chinese vocabulary; the Chinese font and
its license are embedded.

## Limits of the result

The independent checks establish faithful transcription, calculations, rendered
coordinates and synthesized outputs. They do not repeat the museum experiment,
validate its instruments, recover ancient tuning intentions, or establish the
original performance. Automated accessibility checks supplement rather than
replace a screen-reader study. Public deployment is recorded separately in
`publication.json` and `hosted-verification.json` after independent hosted verification.

The published site was checked in four fresh browser configurations. All sixteen
canonical files and the directory entry match the reviewed clean build. Shared
439 Hz state, keyboard reset, audio and offline illustrated exports passed.
